# Linkora

## Avvio locale

Fai doppio clic su `Avvia Linkora.bat` per aprire la dashboard sul tuo computer. Serve Node.js 18 o più recente. La versione locale è una prova: i link condivisi diventano pubblici dopo la pubblicazione su Cloudflare.

## Pubblicazione gratuita

Per avere QR e link brevi raggiungibili da tutti senza comprare un dominio, segui [le istruzioni Cloudflare](cloudflare/README.md) e avvia `cloudflare/Installa Linkora gratis.bat`. L'indirizzo pubblico sarà `workers.dev`.

La configurazione Cloudflare usa Workers e D1 nel piano gratuito entro i limiti indicati nel README Cloudflare. Un dominio come `linkora.tk` è facoltativo e può avere un costo.
