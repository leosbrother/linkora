LINKORA - FILE PER RENDER

Carica questi quattro file nella cartella principale del repository GitHub (Add file > Upload files):
- package.json
- server.js
- linkora.html
- README-RENDER.txt (facoltativo)

Dopo aver salvato il commit sul branch main, in Render apri Settings > Build & Deploy e imposta:
- Root Directory: lascia vuoto
- Build Command: yarn
- Start Command: yarn start

Poi avvia Manual Deploy > Deploy latest commit.
